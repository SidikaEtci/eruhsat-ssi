HOW BLOCKCHAIN WORKS

Step 1: License Is Issued

→ User fills out the form
→ PDF document is uploaded
→ System creates a Verifiable Credential

Step 2: Cryptographic Processing

→ PDF is encrypted with AES-256
→ Uploaded to IPFS and hashed
→ Verifiable Credential is signed (Ed25519)
Example IPFS hash:
QmUHBAEWF6eJs7JXxDiDcJB2oeFRr57cerTFNpKVvhwovG

Step 3: Written to the Blockchain

→ A new block is created
→ Credential data is added
→ Previous block hash is linked
→ New block is hashed
Block #1 hash: a3f5b8...
↓ (used as previous hash)
Block #2: previous_hash = a3f5b8...

Step 4: Verification

→ QR code is scanned
→ Credential is read from the blockchain
→ Signature is verified
→ Dates are checked
→ Revocation status is checked

WHY BLOCKCHAIN?

1. Immutability

Once a license is issued, it cannot be altered retroactively.
The hash chain detects any tampering.

2. Transparency

All actions are recorded.
Who issued which license and when is visible.

3. Decentralization

Not dependent on a single server.
On the Indy network, the system keeps running if one node fails.

4. Cryptographic Security

Ed25519 digital signatures make forgery impractical.
AES-256 encryption blocks unauthorized access.
