🔍 BLOCKCHAIN NASIL ÇALIŞIYOR?

📋 Adım 1: Ruhsat Verilir

→ Kullanıcı formu doldurur
→ PDF belgesi yüklenir
→ Sistem Verifiable Credential oluşturur

🔐 Adım 2: Kriptografik İşlemler

→ PDF AES-256 ile şifrelenir
→ IPFS'e yüklenir → Hash alınır
→ Verifiable Credential imzalanır (Ed25519)
Örnek IPFS Hash:
QmUHBAEWF6eJs7JXxDiDcJB2oeFRr57cerTFNpKVvhwovG

⛓️ Adım 3: Blockchain'e Yazılır

→ Yeni block oluşturulur
→ Credential verisi eklenir
→ Önceki block'un hash'i eklenir
→ Yeni block hash'lenir
Block #1 Hash: a3f5b8...
↓ (önceki hash olarak kullanılır)
Block #2: previous_hash = a3f5b8...

✅ Adım 4: Doğrulama

→ QR kod taranır
→ Blockchain'den credential çekilir
→ İmza doğrulanır
→ Tarih kontrolü yapılır
→ İptal edilmiş mi kontrol edilir

🔐 NEDEN BLOCKCHAIN?

1. Değiştirilemezlik (Immutability)

Bir ruhsat verildikten sonra geriye dönük değiştirilemez.
Hash zinciri sayesinde herhangi bir değişiklik tespit edilir.

2. Şeffaflık

Tüm işlemler kayıt altında.
Kim, ne zaman, hangi ruhsatı verdi → görülebilir.

3. Merkeziyetsizlik

Tek bir sunucuya bağımlı değil.
Indy network'teki 4 node'dan biri çökse bile sistem çalışır.

4. Kriptografik Güvenlik

Ed25519 dijital imza → sahtecilik imkansız.
AES-256 şifreleme → yetkisiz erişim engellenir.
